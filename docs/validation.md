# Validation — BJT DC Bias Web App

เอกสารนี้บันทึกการตรวจสอบผลลัพธ์ของเว็บแอปเทียบกับ **การคำนวณอิสระ**
(คำนวณซ้ำจากสมการในใบงานด้วยสมการที่เขียนไว้ในหัวข้อ "สมการที่ใช้" ของ
`README.md` โดยไม่เรียกใช้โมดูล `dc_bias.py` ของแอปเลย — ผู้อ่านสามารถทำซ้ำได้
ด้วยเครื่องคิดเลขหรือสคริปต์ของตนเอง)

## วิธีตรวจ

1. คำนวณค่าอ้างอิงจากสมการในใบงาน §06 ด้วยสคริปต์อิสระ (ใช้เฉพาะสูตร ไม่ใช้โค้ดของแอป)
2. POST ค่าเดียวกันเข้าที่ `POST /calculate` ของ Flask แล้วอ่านค่าจาก HTML ที่เรนเดอร์จริง
3. เทียบค่าทีละตัวและตรวจ operating region

## ข้อสรุป

- ค่าที่เว็บแสดงตรงกับการคำนวณอิสระทั้ง 3 เคส (ผลต่างอยู่ในระดับการปัดเศษ 3 ตำแหน่ง)
- Case B ยืนยันว่าผลลัพธ์คำนวณจากอินพุตจริง ไม่ใช่ค่าคงที่ใน HTML
- Case C ยืนยันว่าเมื่อออกนอก forward-active แล้วเว็บแจ้ง warning ไม่รายงานว่าใช้ได้

## ข้อจำกัด

แบบจำลองนี้เป็น forward-active approximation ที่ถือ β และ VBE คงที่ ไม่ใช่การจำลอง
SPICE จึงไม่ครอบคลุมEarly effect, breakdown, ความร้อน หรือพฤติกรรม AC/transient
