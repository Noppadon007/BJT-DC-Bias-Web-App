# Reflection — Lab 02

## 1. ทำไมการเปิด `templates/index.html` ตรง ๆ จึงไม่เท่ากับการรัน Flask

ไฟล์ `index.html` เป็นเพียง **template** ที่มีช่อง `{{ }}` ของ Jinja รอให้ server
เติมค่าลงไป ถ้าเปิดด้วย `file://` เบราว์เซอร์จะไม่รู้จัก Jinja และไม่มีโปรแกรมใด
คำนวณ DC Bias ให้ ตัวแปรจะว่างหรือแสดงเป็นข้อความดิบ

การรัน Flask ทำให้เกิด process จริงที่รับ HTTP request, เรียกฟังก์ชัน Python ใน
`dc_bias.py`, แล้วนำผลไปประกอบเป็น HTML ส่งกลับมา ดังนั้นตัวเลขที่เห็นจึงมาจาก
การคำนวณ ไม่ใช่จากไฟล์ที่เขียนค้างไว้

## 2. ฟอร์มส่งข้อมูลไป Python อย่างไร

`<form method="post" action="/calculate">` ทำให้เบราว์เซอร์รวมค่าของทุกช่อง
(ที่มี `name` ตรงกับ `vcc, r1, r2, rc, re, beta, vbe`) เป็น request body แล้วส่ง
HTTP POST ไปที่ path `/calculate`

ฝั่ง Flask อ่านค่าจาก `request.form` ซึ่งเป็น mapping ของข้อความ → ส่งเข้า
`parse_inputs()` เพื่อแปลงเป็นตัวเลข เปลี่ยนหน่วย kΩ เป็น Ω และตรวจความถูกต้อง
ถ้าผ่านจึงเรียก `calculate_voltage_divider()` คำนวณ แล้วเรนเดอร์ template กลับไป

## 3. แก้สมการใน `dc_bias.py` แล้วต้องแก้ HTML หรือไม่

**ไม่ต้อง** เพราะ template ทำหน้าที่แสดงค่าตาม key ที่ Flask ส่งไป (`display.vb`,
`display.ic` ฯลฯ) ไม่ได้มีสมการอยู่ในตัว

ถ้าแก้สมการ เช่น เปลี่ยนวิธีคำนวณ `IC` ผลลัพธ์ใหม่จะไหลไปถึงหน้าจอเอง แต่ถ้า
**เพิ่มปริมาณใหม่** ที่ยังไม่มีใน template จะต้องเพิ่มทั้ง key ใน `format_result()`
และแถวในตาราง — เป็นการเปลี่ยน "สิ่งที่แสดง" ไม่ใช่ "วิธีคำนวณ"

## 4. ทำไมผลใน Region ที่แบบจำลองใช้ไม่ได้จึงต้องมี Warning

สมการที่ใช้มาจากสมมติฐาน forward-active: รอยต่อ base-emitter forward bias และ
รอยต่อ base-collector reverse bias เมื่อวงจรจริงอยู่ใน **cutoff** (`VTH ≤ VBE`)
กระแส base ที่คำนวณได้จะติดลบ ซึ่งไม่มีความหมายทางกายภาพ และเมื่อ **ใกล้
saturation** (`VCE` ต่ำมาก) กระแส collector จะไม่เป็น `β·IB` อีกต่อไป

ถ้าไม่แจ้งเตือน ผู้ใช้อาจนำตัวเลขที่ผิดสมมติฐานไปใช้ต่อโดยเข้าใจว่าเป็นการจำลอง
ที่แม่นยำ — ซึ่งอันตรายกว่าไม่มีตัวเลขเลย Warning จึงเป็นส่วนหนึ่งของความถูกต้อง
ทางวิศวกรรม ไม่ใช่การตกแต่ง UI

## 5. สิ่งที่ได้เรียนรู้เพิ่มเติม

  และเมื่อเพิ่ม bias topology อื่นในสัปดาห์ถัดไปก็ต่อยอดได้ที่จุดเดียว
- การเขียน test ก่อนทำให้เห็นว่า validation ที่ขาดไปจะทำให้หน้าเว็บ 500 แทนที่จะ
  แจ้ง error — การทดสอบบังคับให้จัดการกรณีนั้นจริง ๆ
- การคำนวณอิสระแล้วเทียบผล (`docs/validation.md`) จับข้อผิดพลาดด้านหน่วยได้
  เช่น การลืมคูณ kΩ เป็น Ω ซึ่งจะทำให้กระแสผิดไป 1000 เท่า
